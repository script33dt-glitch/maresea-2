
# 🌸 MARESEA — Moda Praia

Uma experiência digital desenvolvida para a Maresea, uma loja de moda praia que busca unir elegância, feminilidade e praticidade em sua presença online.

O projeto apresenta uma vitrine virtual com identidade visual delicada, tons rosados, tipografia elegante e navegação adaptada para dispositivos móveis.

## ✨ Sobre o projeto

O site foi desenvolvido com HTML, CSS e JavaScript, priorizando uma experiência visual agradável, navegação intuitiva e facilidade de contato com os clientes.

### 🎀 Identidade visual
- Fundo predominantemente branco.
- Paleta de cores em rosa, vinho e tons suaves.
- Tipografia elegante e feminina.
- Fotografias em destaque.
- Layout responsivo.

## 📂 Estrutura do projeto

```text
MARESEA/
│
├── index.html
├── colecao.html
└── README.md
```

## 🛍️ Páginas

### 01. Página inicial — `index.html`

- Apresentação da marca Maresea.
- Banner principal.
- Produtos em destaque.
- Chamada para conhecer a coleção.
- Navegação para o catálogo.

### 02. Catálogo — `colecao.html`

- Vitrine de produtos.
- Categorias de produtos.
- Filtros interativos.
- Exibição de preços.
- Botões de consulta e compra.
- Integração preparada para WhatsApp.

## ⚙️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estrutura das páginas |
| CSS3 | Estilização e responsividade |
| JavaScript | Filtros e interações |

## 📱 Responsividade

O projeto foi desenvolvido para funcionar em:
- Computadores.
- Tablets.
- Smartphones.

## 📞 Atendimento

O projeto possui estrutura preparada para integração com WhatsApp, permitindo que os clientes consultem produtos e iniciem o atendimento diretamente pela loja.

O número comercial deverá ser configurado na variável `WHATSAPP_NUMBER` do arquivo correspondente.

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Entre na pasta:

```bash
cd MARESEA
```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para a visualização local.

## 📌 Observações

Os produtos, valores e fotografias utilizados na versão inicial são demonstrativos e deverão ser substituídos pelas informações oficiais da loja.
